# Michael Burry SEC analysis

Run `../warren-buffett-sec/scripts/sec_analysis.py TICKER` with `SEC_CONTACT_EMAIL` set. The shared Python script compares operating cash flow with net income in each of five fiscal years and latest total liabilities with stockholders' equity. Missing inputs remain **Not Known**. Use only printed numbers in a short, clearly labeled Burry-style simulation memo. Discuss cash backing earnings and balance-sheet resilience, while stating that this screen alone cannot establish earnings manipulation, valuation, or hidden risks.

The skeptical cash-flow lens is adapted from [the Michael Burry expert reference](https://github.com/CinderZhang/FAskills/blob/main/financial-researcher/experts/michael_burry.md).
